# Notebook status

`Anime StackViz.ipynb` is the original university-assignment artifact and is kept for provenance.
It is not the authoritative analysis: some narrative claims and aggregations in that notebook were
superseded during the portfolio redevelopment.

The reproducible implementation now lives in `src/anime_stackviz/`. Run it with:

```bash
anime-stackviz analyse --data-dir data --report-dir reports
```

The generated audit, metrics, predictions, and figures are written to `reports/`.
